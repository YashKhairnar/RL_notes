n-step Bootstrapping: Complete Chapter 7

Self-contained study guide for Sections 7.1–7.7 of Reinforcement Learning: An Introduction (2nd edition) by Richard S. Sutton and Andrew G. Barto—bridging one-step TD and full-episode Monte Carlo.

One-step TD and Monte Carlo are just the two ends of an n-step spectrum.

In Chapter 5 (MC), you waited until the very end of the episode to update. In Chapter 6 (TD(0)), you updated after just 1 step. n-step bootstrapping lets you choose any intermediate horizon n: collect n real rewards, then bootstrap from the estimated value of the state you reach n steps later. In practice, an intermediate n (like 4 or 8) almost always learns faster than either extreme.

7.1 n-step TD prediction

Consider estimating vπ from sample episodes generated using π:

  • Monte Carlo methods update each visited state based on the entire sequence of rewards from that state until the end of the episode.
  • One-step TD methods update based on the next reward only, bootstrapping from the very next state.
  • n-step TD methods sit in between—still TD (we bootstrap by changing an earlier estimate based on how it differs from a later estimate, only that the later estimate is now n steps later).

Targets: from n = 1 to n = ∞

Let Vt : S → R be the estimate at time t of vπ, and write Gt:t+n for the n-step return from time t to t + n:

n = 1 (TD) Gt:t+1 ≐ Rt+1 + γ Vt(St+1) n = 2 Gt:t+2 ≐ Rt+1 + γ Rt+2 + γ2 Vt+1(St+2) ⋮ n = ∞ (MC) Gt:T ≐ Rt+1 + γ Rt+2 + ··· + γT−t−1 RT
General n-step target (Eq. 7.1): Gt:t+n ≐ Rt+1 + γRt+2 + ··· + γn−1Rt+n + γnVt+n−1(St+n) for t + n < T (otherwise full Gt).

All n-step returns are approximations of the full return, truncated after n steps and corrected for the remaining steps by Vt+n−1(St+n). Because n-step returns for n > 1 depend on future rewards not yet available at t → t + 1, the update to St happens at time t + n:

Vt+n(St) ≐ Vt+n−1(St) + α [ Gt:t+n − Vt+n−1(St) ] Eq. (7.2) · No changes are made during the first n−1 steps of an episode; to make up for that, an equal number of updates happen after termination before the next episode starts.

Why n-step TD converges: the Error-Reduction Property

An essential mathematical guarantee of n-step returns is that their expected value is strictly closer to vπ than the bootstrapped estimate Vt+n−1 is, in the worst-state sense:

maxs ∈ S | Eπ[ Gt:t+n | St = s ] − vπ(s) | ≤ γn maxs ∈ S | Vt+n−1(s) − vπ(s) | Eq. (7.3) · Error-reduction property: worst-case error shrinks by γn (even faster than 1-step's γ). 
Algorithm: n-step TD for estimating V ≈ vπ
Initialize V(s) arbitrarily for all s ∈ S; store states & rewards in circular buffer of size n+1
Loop for each episode:
    Initialize and store S0 ≠ terminal; T ← ∞
    For t = 0, 1, 2, ...:
        If t < T:
            Take action At ~ π(· | St), observe Rt+1 and St+1
            Store Rt+1 and St+1; if St+1 is terminal, then T ← t + 1
        τ ← t − n + 1   (τ is the time whose state's estimate is being updated)
        If τ ≥ 0:
            G ← Σi=τ+1min(τ+n, T) γi−τ−1 Ri
            If τ + n < T: G ← G + γn V(Sτ+n)
            V(Sτ) ← V(Sτ) + α [ G − V(Sτ) ]
    Until τ = T − 1

7.2 n-step Sarsa (and Expected Sarsa)

To move from prediction to control, swap state values V for action values Q. In n-step Sarsa, we sum n rewards and bootstrap from Qt+n−1(St+n, At+n):

Gt:t+n ≐ Rt+1 + γ Rt+2 + ··· + γn−1 Rt+n + γn Qt+n−1(St+n, At+n) Eq. (7.4) · Update: Qt+n(St, At) ← Qt+n−1(St, At) + α [ Gt:t+n − Qt+n−1(St, At) ]

n-step Expected Sarsa: Replace the final sampled Qt+n−1(St+n, At+n) with the expected value over all actions under π. That removes the variance of sampling the final action At+n:

Vt+n−1(St+n) ≐ Σa π(a | St+n) Qt+n−1(St+n, a) Eq. (7.8) · Expected Sarsa bootstraps from Vt+n−1(St+n) instead of Qt+n−1(St+n, At+n).

7.3–7.4 Off-policy n-step & control variates

In off-policy learning (target policy π, behavior policy b), an n-step return only needs importance sampling over the n actions actually taken in that window—not the entire episode:

Vt+n(St) ≐ Vt+n−1(St) + α ρt:t+n−1 [ Gt:t+n − Vt+n−1(St) ] ρt:h ≐ min(h, T−1)Πk = t π(Ak | Sk)b(Ak | Sk) Eq. (7.9)–(7.10) · For n-step Sarsa, use ρt+1:t+n (since At is already fixed on the left-hand side).

7.4 *Per-decision methods with control variates (reducing variance)

The problem with naive ρt:t+n−1: If π(Ak | Sk) = 0 at any step, then ρ = 0, which zeroes out the entire update—wasting data (and if you multiply the target G by 0 instead of the error, it pulls V toward 0!). Control variates fix this by writing the n-step return recursively per step:

Gt:h ≐ ρt ( Rt+1 + γ Gt+1:h ) + (1 − ρt) Vh−1(St) Eq. (7.13) · If ρt = 0, then Gt:h = Vh−1(St), so the update error Gt:h − Vh−1(St) = 0 (cleanly ignored!).

7.5–7.6 Tree Backup & unifying n-step Q(σ)

7.5 Off-policy without importance sampling (Tree Backup): Q-learning and Expected Sarsa did 1-step off-policy control with zero importance sampling. How do you extend that to n steps? At every step along the sampled trajectory, average over the unselected actions using their current Q values weighted by π(a | S), and pass the remaining π(At+1 | St+1) weight down to the next sampled step:

Gt:t+n ≐ Rt+1 + γ Σa ≠ At+1 π(a | St+1) Qt+n−1(St+1, a) + γ π(At+1 | St+1) Gt+1:t+n Eq. (7.16) · Off-policy multi-step learning with zero importance-sampling variance.

7.6 *A unifying algorithm: n-step Q(σ)

Introduce a parameter σt ∈ [0, 1] at each step to slide smoothly between sampling (σ = 1, like Sarsa) and expectation (σ = 0, like Tree Backup):

  • σk = 1 everywhere: Reduces to n-step Sarsa (with control variates if off-policy).
  • σk = 0 everywhere: Reduces to n-step Tree Backup.
  • σk = 1 except σt+n = 0: Reduces to n-step Expected Sarsa.

7.7 Summary

Chapter 7 bridges one-step TD and Monte Carlo methods. All n-step algorithms share one practical drawback: they require a delay of n steps before any update can occur (and storing n steps of experience)—a limitation that Chapter 12's eligibility traces will eliminate.

Error Reduction

Expected n-step returns shrink worst-case error by γn, and intermediate n typically outperforms both n=1 and MC.

Off-Policy via IS

Importance sampling + control variates reweights trajectories without shrinking estimates when ρ = 0, though variance can still be high.

Off-Policy via Tree Backup

Tree Backup & Q(σ) generalize Expected Sarsa to n steps with zero importance-sampling variance.
